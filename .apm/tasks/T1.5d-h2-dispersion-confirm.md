# T1.5d — H2 Check dispersion-control + dual-metric confirmatory run

**Agent:** tda-agent-2 (APM Worker) · **Branch/worktree:** `run/h2-positive-control` · **Papers:** P01-A / P01-B (shared H2 restriction) · **Dispatched by:** Manager 10 · **Follows:** T1.5c Phase A (escalated) + Manager inline scoping

## Why this run (READ FIRST)
T1.5c refuted the threshold-artifact hypothesis (pinned ≈ auto). Manager scoping then found the H2 W2 rejection is a **cloud-dispersion shift, not void structure**: the observed H2 diagram is the Markov-1 null diagram **shifted ~35% to larger birth/death coordinates** (L=200 obs birth med 15.03 vs null 11.15; L=300 13.56 vs 10.17), with similar persistence spans. That is the *same* dispersion driving H0 (T≈15) / H1 (T≈5-7) — not additive beyond the omnibus. The raw/pinned W2 "rejection" is therefore **dispersion-confounded** and not a valid basis for "expand to H2".

**Governing pre-registration:** `results/trajectory_tda_integration/stage1/pre_registrations_h2_dispersion_2026-06-18.json` (amends the 2026-06-18 pinned amendment). Decision rule UNCHANGED (*reject → expand; fail → restriction stands*) but applied to the **scale-normalized dual-metric** statistic.

## Objective
Determine whether the H2 difference vs the Markov-1 null survives **scale normalization** (dispersion control) under the **mandatory dual metric** (W2 + landscape-L2). Expected: it vanishes → restriction stands.

## Method (lock)
For **L ∈ {200, 300}**, **B=50**, **seed=42**, **Markov-1**, dense ripser maxdim=2, `do_cocycles=False`:

1. **Dispersion control (normalization).** For every cloud (observed and each null L-landmark sample), compute `s = median(pdist(landmarks))` and run PH on **distances divided by `s`** (equivalently scale the cloud by `1/s`). Observed and each null are normalized by **their own** `s`. Threshold is immaterial here (Phase A: pinned ≈ auto) — use the per-cloud auto-threshold on normalized distances.
2. **Dual metric for H2** (per CONVENTIONS — co-primary, no W2-alone conclusion):
   - **W2**: order 2, internal_p 2.
   - **Landscape-L2**: k_max=5, n_points=200 (project-standard; reuse `trajectory_tda/topology/vectorisation` landscape machinery, as the headline battery / `_battery_core` does).
   - For each metric: obs-null distribution (B=50) + 500-pair null-null baseline (seed 42); report mean(obs-null), mean(null-null), T-ratio, and `(r+1)/(B+1)` p-value.
3. **Reference (raw) condition.** Also run the **unnormalized** W2 + landscape-L2 at the same settings, as the confound exhibit (raw should reject; normalized should not).
4. **Descriptive provenance.** Report obs vs null H2 **birth/death medians** raw and normalized (to show the location shift collapses under normalization).

## Decision logic (from the pre-reg)
- **BOTH normalized metrics fail to reject** (W2 p≥0.05 AND landscape-L2 p≥0.05) at **both** L → **restriction stands** (dispersion confirmed; the H2 difference is the H0/H1 signal, not additive). This is the expected outcome.
- **EITHER normalized metric rejects** (p<0.05) at either L → **STOP and escalate** to the Manager before any prose (scale-invariant H2 candidate; not auto-promoted).
