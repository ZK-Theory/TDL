# T1.5c — H2 Check matched-scale diagnostic (pinned-threshold; small-L first)

**Agent:** tda-agent-2 (APM Worker) · **Branch/worktree:** `run/h2-positive-control` (`.apm/worktrees/run-h2-positive-control`) · **Papers:** P01-A / P01-B (shared H2 restriction) · **Dispatched by:** Manager 10 · **Reissue of:** T1.5b (escalated 2026-06-18)

## Why this reissue (READ FIRST)
The 2026-06-17 L=1000 H2 rerun (`00089f3`) **rejected** on the Markov-1 null in all three dims (H0 T=14.85 / H1 T=7.35 / H2 T=5.16, all p=0.0), contradicting the 2026-05-02 baseline (H2 p=0.690 ns). Manager root-cause review found this is **not a trustworthy H2 signal** but a **threshold-comparability artifact**: `compute_rips_ph` uses a *per-cloud* adaptive 75th-pct threshold, so the observed cloud (auto-thresh **22.26**) and the 50 null clouds (auto-thresh **~15.5**) sit on **different filtration scales**. Global-Markov-1 surrogates are genuinely less dispersed than the real data, so the W2 statistic confounds dispersion/scale with void topology (signature: monotone all-dim rejection H0>H1>H2). Loadings are correctly frozen+shared and seeds vary correctly — this is a **method-design confound, not a bug**.

**Governing pre-registration:** 2026-05-13 "H2 Check" → 2026-06-17 (L→1000) → **2026-06-18 threshold-comparability fix** → `results/trajectory_tda_integration/stage1/pre_registrations_2026-06-18.json`. Decision rule **UNCHANGED**: *reject → expand to H2; fail → restriction stands* — now applied to the **pinned-threshold** (matched-scale) statistic.

## The fix (already in the codebase — reuse, don't reinvent)
`trajectory_tda/scripts/stage1/_battery_core.py` `probe_pinned_thresh` (≈ lines 575-589) computes `tau = pdist(obs_landmarks).max()` (observed enclosing radius) and passes it as ripser `thresh` to **both** the observed PH and every null PH via `_single_permutation(..., pinned_thresh=tau)`. This is the **same probe** that confirmed the P01-A H1 length-matched W2 rejection is robust (`results/trajectory_tda_bhps/stage1/bhps_length_matched_truncate_frozen_probe-pinned-thresh_2026-05-31.json`). The H2 path uses `dedup=False` → observed and null already have **equal** vertex counts (1000 each), so the confound is **threshold-only**; **do NOT** use `forced_n_dedup`/`probe_symmetric_dedup`.

## Phase A — small-L matched-scale diagnostic (THIS dispatch's deliverable)
At **L ∈ {200, 300}** (optionally add 150), run the H2 Check — observed H2 + **B=50** Markov-1 nulls, **seed=42**, `do_cocycles=False`, dense ripser — **twice on the identical landmark samples**:
1. **auto-thresh** (production per-cloud 75th-pct) — should reproduce the rejection-like gap.
2. **pinned tau = `pdist(obs_landmarks).max()`** applied to observed + all 50 nulls.

For each L and each condition, report **H0/H1/H2**: `mean_wasserstein_obs_null`, `mean_wasserstein_null_null`, `t_ratio`, `p_value`, plus the `tau`/auto-thresh values and `edge_prop_at_thresh` actually used.

**Decisive read:** if the **H2 T-ratio collapses toward ~1 (fail to reject)** under the pinned threshold while persisting under auto-thresh, the 2026-06-17 rejection is confirmed as the threshold-scale artifact → expected branch *restriction stands*. Small-L H2 is cheap (≈0.3 s/cloud at L=200), so B=50 × 2 L × 2 conditions is minutes.

**Feasibility note:** the enclosing-radius pin pushes both clouds toward full edge density, so record the H2 tetra burden the pre-flight gate estimates at each L; this maps where the matched-scale H2 stops being feasible (it will NOT be feasible at L=1000 — that is itself a finding).
