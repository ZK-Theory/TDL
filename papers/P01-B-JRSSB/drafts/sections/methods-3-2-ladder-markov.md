# §3.2 The Markov Memory Ladder: Stratified Rung and Laplace-Smoothed Markov-2

## The ladder

Each formal level specifies a null model of increasing fidelity to the observed process; $B\geq1{,}000$ surrogate trajectory sets are drawn per inferential level, re-embedded with the frozen PCA loadings (§3.1), and landmarked independently per surrogate (maxmin, same seed policy as the observed cloud). Each formal level tests whether the observed persistence diagram exceeds what its null process would produce.

- **Level 3 -- Order shuffle.** $H_0^{(3)}$: the *set* of states visited matters but their temporal order does not (within-trajectory state multiset preserved, order permuted).
- **Level 4 -- Markov order-1.** $H_0^{(4)}$: surrogate trajectories are drawn from a first-order Markov chain with transition matrix $\hat P$ estimated by maximum likelihood on the full pooled sample, conditional on each trajectory's observed starting state and length.

### Level 4b -- Stratified Markov order-1 (new)

**What this rung tests.** Level 4 asks whether the *pooled* population's topology exceeds a single, globally-estimated first-order Markov null. Level 4b asks a different, per-subgroup question: for a stratification family $a$ (gender, parental NS-SEC, or birth cohort) with subgroups $g \in \{1,\ldots,G_a\}$, does each subgroup's *own* topology, taken alone, exceed *its own* first-order Markov baseline? This is a test of **per-subgroup Markov-1 irreducibility**, not a test of whether subgroups differ from one another (that is a distinct, pairwise-heterogeneity question this rung does not address; see Note below).

Formally, for subgroup $g$:
$$
H_0^{(4b,g)}:\ D_q(X_g) \text{ is consistent with surrogates generated by a first-order
Markov chain } \hat P_g \text{ estimated on subgroup } g\text{'s own trajectories.}
$$

**Construction:**

```
for each subgroup g in family a:
    trajectories_g <- trajectories with grouping_key[a] == g
    if |trajectories_g| >= 30:
        P_hat_g <- MLE first-order transition matrix estimated on trajectories_g only
    else:
        P_hat_g <- global (pooled) transition matrix   # small-subgroup floor, n < 30
    for b in 1..B:
        simulate synthetic trajectories from P_hat_g, matching each member's
            observed starting state and length
    re-embed synthetic trajectories with frozen PCA loadings
    landmark independently (maxmin, min(5000, n_g) landmarks)
    compute D_q(X_g^null_b) for b in 1..B
compare D_q(X_g) (observed) against the ensemble {D_q(X_g^null_b)}_{b=1}^{B}
    via T_g = mean_b W_2(D_q(X_g), D_q(X_g^null_b)) / mean W_2(null, null)   (§3.3)
```

Note that the transition matrix is re-estimated **within** each subgroup (not the global $\hat P$ applied to subgroup $g$'s starting states) — this is what makes the test one of subgroup-specific Markov-1 irreducibility rather than a global-null-applied-locally test. Subgroups below $n=30$ trajectories fall back to the global transition matrix as an estimation-stability floor; no stratified subgroup analysed here falls below this threshold (smallest cells: BHPS 1980s cohort $n=223$, Professional/Managerial $n=335$).

**Parameters:** $B = 1{,}000$ Markov-1 surrogates per subgroup, seed 42, landmark count $\min(5{,}000, n_g)$, frozen PCA-20 loadings, dual-metric ($W_2$ and persistence-landscape $L^2$), 95% BCa bootstrap interval on $T_g$, permutation $p = (r+1)/(B+1)$.

**Multiplicity correction.** The three stratification families are corrected separately by Benjamini-Hochberg: gender ($G=2$), parental NS-SEC ($G=3$), and birth cohort ($G=7$ USoc / $G=6$ BHPS). This use of BH assumes independent or positively dependent test statistics within each family; disjoint cohort membership alone does not establish that assumption. The families and correction procedure remain as specified in the pre-registration amendment.

> **Note on stratification axis.** The per-group null is defined generically over any grouping variable. Level 4b as reported here uses the three **demographic** stratification families (gender, parental NS-SEC, birth cohort). A GMM-derived topological regime stratification addresses a different question — per-subgroup irreducibility conditional on latent regime membership — and would constitute a distinct rung rather than a variant of Level 4b; it is not reported here and should not be conflated with the demographic rung above.

- **Level 5 -- Markov order-2.** $H_0^{(5)}$: surrogate trajectories are drawn from a second-order Markov chain with transition matrix $\hat P^{(2)}$ estimated by maximum likelihood on the full pooled sample, conditional on each trajectory's observed first two states, with **Laplace (add-one) smoothing at $\alpha = 1$** applied to all $|\mathcal{S}|^2 = 81$ two-step conditioning cells:
$$
\hat P^{(2)}(s_t \mid s_{t-2}, s_{t-1}) = \frac{\mathrm{count}(s_{t-2}, s_{t-1}, s_t) +
\alpha}{\sum_{s} \mathrm{count}(s_{t-2}, s_{t-1}, s) + \alpha\,|\mathcal{S}|},
\qquad \alpha = 1.
$$
  Unobserved bigram contexts receive the uniform fallback $1/|\mathcal{S}|$ (the $\alpha \to$ uniform limit of the same formula). The choice of $\alpha = 1$ is empirically motivated by a sensitivity sweep over $\alpha \in \{0, 0.5, 1, 5\}$ ($L=5{,}000$, $B=1{,}000$, seed 42): the rejection **direction** is stable across the full range for both datasets and both homological degrees. USoc rejects the Markov-2 null at every $\alpha$ for both $H_0$ and $H_1$ ($p<0.001$ throughout); BHPS rejects $H_0$ at every $\alpha$ ($p<0.001$) but fails to reject $H_1$ at every $\alpha$ ($p=0.98$ at $\alpha=0$ to $p=0.86$ at $\alpha=5$). No smoothing strength in the swept range changes which dataset/dimension combinations reject, so the Markov-2 conclusion reported in §4.2 is not an artefact of the smoothing-parameter choice.

## Procedure

$B\geq1{,}000$ surrogates per inferential analysis, frozen PCA loadings for surrogate re-embedding, and maxmin landmarks re-selected independently per surrogate.

### Invalidated historical audit

The retired label-shuffle and cohort-shuffle procedures are retained only as a historical audit. Both permuted rows after embedding while the persistence construction is set-valued, leaving the statistic invariant; they are not formal nulls and their p-values have no inferential interpretation.
