## Research Context Header

New Python scripts must include the mandatory research context header at the top of the file:

```python
# Research context: TDA-Research/03-Papers/P01-A/_project.md
# Purpose: [what this script does in the research context]
```

## Paper and draft conventions

- Use versioned drafts in `papers/PXX/drafts/`.
- Do not rewrite previous draft versions.
- Update `_project.md` open items, status, or notebook references when work completes.

## Repository conventions

- Keep long-form methodological guidance in the dedicated instruction files.
- Preserve the root policy file for active enforcement only.
